# Дорнод 2006 — Төгсөгчдийн вэб сайт

Дорнод аймгийн ерөнхий боловсролын сургуулиудыг 2006 онд төгссөн төгсөгчдийн нэгдсэн сайт.
Node.js (Express + EJS) болон MySQL ашиглана. Railway дээр ажиллахаар тохируулсан.

## Боломжууд

| Хэсэг | Тайлбар |
|---|---|
| **Бүртгэл / нэвтрэх** | Төгсөгч утасны дугаар, нууц үгээр бүртгүүлнэ. Админ баталгаажуулсны дараа бүрэн эрх нээгдэнэ. |
| **Мэдээ, зарлал** | Админ нийтэлнэ. Онцлох мэдээг дээр байрлуулна. |
| **Төгсөгчид** | Баталгаажсан төгсөгчид бие биенээ нэр, сургууль, ажил, хотоор хайна (холбоо барих мэдээлэл зөвхөн гишүүдэд). |
| **Миний хуудас** | Нууц үг солих, админд засварын хүсэлт илгээх, ирсэн нэр дэвшүүлэлтэд хариу өгөх. |
| **Сонгууль** | 4 шаттай: нэр дэвшүүлэх → зөвшөөрөл → санал хураалт (шууд явц) → дүн, статистик. |
| **Админ** | Бүртгэл батлах/татгалзах, төгсөгчийн мэдээлэл засах, нууц үг шинэчлэх, мэдээ, сургууль, хүсэлт, сонгууль удирдах. |

Бүх мэдээллийн өөрчлөлтийг **админ** хийнэ. Төгсөгчид зөвхөн нууц үгээ өөрөө сольж, бусад өөрчлөлтийг хүсэлтээр илгээнэ.
Админ: **Бумцэнд овогтой Алтанхуяг** (8-р сургууль).

### Сонгуулийн урсгал

1. **Нэр дэвшүүлэх** — баталгаажсан төгсөгч өөрийгөө эсвэл бусдыг нэр дэвшүүлнэ (үндэслэлтэй). Нэг хүнийг олон хүн дэмжиж болно. Өөрийгөө дэвшүүлбэл автоматаар зөвшөөрсөнд тооцогдоно.
2. **Зөвшөөрөл авах** — нэр дэвшигч "Миний хуудас" эсвэл сонгуулийн хуудаснаас зөвшөөрөх/татгалзах, мөрийн хөтөлбөрөө бичнэ.
3. **Санал хураалт** — зөвхөн зөвшөөрсөн нэр дэвшигчид саналын хуудсанд орно. Нэг хүн нэг удаа, тохируулсан тооноос ихгүй нэр дэвшигч сонгоно.
   Явц (ирц, сургуулиар оролцоо, цаг тутмын идэвх, сүүлд ирсэн санал) 10 секунд тутам шинэчлэгдэнэ. Нэр дэвшигчдийн саналыг шууд харуулах эсэхийг админ тохируулна.
4. **Дүн** — нэр дэвшигч бүрийн санал, хувь, сонгогдсон гишүүд (★), ирц, сургуулиар ирц, цагийн график.

**Нууц санал:** хэн санал өгснийг л (давхар санал өгөхөөс сэргийлж) тэмдэглэнэ. Хэнд өгснийг өгөгдлийн санд огт хадгалахгүй — нэр дэвшигчийн саналын тоо л нэмэгдэнэ.
Шатыг админ гараар солино. Санал өгөгдсөний дараа өмнөх шат руу буцах боломжгүй.

## Railway дээр байршуулах

1. Энэ хавтсыг GitHub-д push хийнэ.
2. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → энэ репо.
3. Төсөл дотор **+ New → Database → MySQL** нэмнэ.
4. Вэб сервисийн **Variables** хэсэгт:

   | Нэр | Утга |
   |---|---|
   | `DATABASE_URL` | `${{MySQL.MYSQL_URL}}` |
   | `NODE_ENV` | `production` |
   | `SESSION_SECRET` | урт санамсаргүй тэмдэгт мөр |
   | `ADMIN_PHONE` | админы утасны дугаар (нэвтрэх нэр) |
   | `ADMIN_PASSWORD` | админы анхны нууц үг |

5. **Settings → Networking → Generate Domain** дарж нийтийн хаяг авна.

Анх асахдаа хүснэгтүүд автоматаар үүсч, сургуулиудын анхны жагсаалт болон админ хэрэглэгч (Бумцэнд Алтанхуяг) үүснэ.
Нэвтэрсний дараа админ нууц үгээ "Миний хуудас" хэсгээс солих нь зүйтэй.

`SESSION_SECRET` үүсгэх: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

## Локал дээр ажиллуулах

```bash
npm install
cp .env.example .env   # DATABASE_URL болон бусад утгыг засна
npm run dev            # http://localhost:3000
```

MySQL дээр `dornod2006` нэртэй өгөгдлийн сан урьдчилан үүсгэсэн байх шаардлагатай.
